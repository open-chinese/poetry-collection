# 中国古诗词的起源、发展与存世文献规模

## ——分阶段考察及其整理的意义与挑战

**报告日期：2026年10月25日**  
**研究性质：基于外部文献的历史综述与数量口径核查**


## 摘要

中国古诗词并不是一种形式在两千多年间的简单延续。从早期礼乐活动中的歌辞，到《诗经》与楚辞所呈现的不同抒情传统；从汉代乐府、五言诗，到魏晋南北朝的文人诗与声律探索；再到唐代诗体的成熟、宋代诗词的并盛、元代散曲的发展，以及明清规模庞大的诗词创作，它始终在语言、音乐、制度、传播方式和个人经验的交汇处变化。

关于数量，首先需要区分三个问题：**当时写过多少、今天还保存多少、某一整理本收了多少。** 三者不能互相替代。《诗经》有正文305篇，是边界相对明确的经典文本规模；《唐五代诗全编》收诗57000余首、《全宋诗》收诗接近25万首、《全元诗》收诗约14万首，则分别是特定整理成果的规模。清诗800万至1000万首的说法属于学者对文献遗存的估算，不能与上述数字不加说明地并列为“精确存量”。

这份报告的基本判断是：古诗词整理的意义，不只是让名篇更容易检索，更在于尽可能恢复一个长期积累、不断散佚、反复重编的文化世界。可靠的整理必须同时保留作品、版本、作者归属和不确定性；否则，数字越大，反而可能离文献事实越远。

**关键词：** 中国诗歌史；古诗词；断代总集；存世数量；文献整理；数字人文

## 一、研究范围与统计方法

### 1.1 本报告中的“中国古诗词”

本报告主要讨论以汉语书写、进入中国古典文学传承体系的诗与词，包括古体诗、近体诗、乐府诗及词。元代散曲作为与诗词关系密切的韵文形式，另栏讨论；杂剧、传奇则不按“诗词首数”计入。

这一范围并不等于中国境内全部民族、全部语言的诗歌遗产。蒙古族、满族等不同群体的汉语诗词创作属于本报告的讨论范围，但其他语言中的口传史诗、民歌及其汉译本，需要另设语种、文本形态和统计单位。不能把汉语总集的数量直接称为“中国所有诗歌的数量”。

时间上以先秦至清末为主体，以1911年作为近代部分的叙述性截点。古典诗词在此后仍然持续创作，王朝结束不意味着文体结束；只是民国及当代旧体诗词不纳入本报告的数量讨论。

### 1.2 “存量”为什么不能只给一个数字

| 概念 | 实际回答的问题 | 最容易出现的误用 |
|---|---|---|
| 历史创作量 | 某一时期一共创作过多少作品 | 用今天保存下来的作品反推全部历史创作 |
| 古代著录量 | 某部目录或史书当时登记了多少篇、卷、家 | 把已经散佚的书目记录当作现存诗篇 |
| 现存文献量 | 今天还能找到多少作品及其文本见证 | 未区分整首、残句、异本与仅存篇名 |
| 总集收录量 | 某一版本的总集编入了多少作品 | 把书名中的“全”理解为永远穷尽 |
| 数字平台记录量 | 某一数据库建立了多少条记录 | 把重出、异文、组诗总题都当作独立作品 |

例如，一首诗在三部别集中出现，可能只有一个作品身份，却有三个值得保留的文本见证；一组题为“五首”的诗，也可能被数据库存成一条，或拆成五条。若不先说明这些处理方式，不同数字之间的差距很可能只是编目方法不同。

本报告采用以下规则：

1. **优先使用能核对来源的整理本数据。** 出版机构、高校及署名学者的资料优先于无出处的网络汇总。
2. **保留原来源的约数性质。** “余”“约”“接近”不改写成精确值。
3. **诗、词、散曲分开。** 散曲的小令以“首”计，套数以“套”计，不把一套直接折算成一首诗。
4. **总集与补编不直接累加。** 必须先处理重收、改署、辨伪及版本关系。
5. **无法核实的阶段总量不填写。** 部分作品群的数量可以提供尺度，但不能冒充整个时期的存量。
6. **旧资料只说明其发表时的情况。** 1997年的工程预计、2013年的项目介绍、2021年的学者估算，不自动等于2026年的工程完成状态。

### 1.3 分期的性质与资料等级

下文使用文学史中常见的阶段划分，但不把它们当作严密互斥的统计区间。建安文学发生于东汉末年，却通常与魏晋诗风的形成合论；辽、宋、金长期并立；唐五代、宋元及明清之际也存在跨朝作者。实际清点时应尽量依作品年代处理，并另记所用总集的断代规则。

为方便阅读，数量结论分为四类：

- **定本或整理本数：** 特定文本、特定版本的明确规模；不保证等于整个时代的独立作品数。
- **文献约数：** 署名学者或专业介绍提供的近似规模，适合量级比较。
- **估算或规划数：** 对尚未穷尽整理的文献体量作出的判断，不能作为完成量。
- **未核定：** 本次未取得足以支持全阶段首数的证据；不表示该阶段没有作品。

文学史叙述参照通行《中国文学史》的分期与基本认识；对于作者归属、文体起源和作品定年存在争议之处，另作限制性说明。[^history]

## 二、起源与先秦：从歌辞传统到《诗经》、楚辞

### 2.1 主要介绍与特点

诗歌的发生应当早于今天能够看到的诗歌文献，但目前无法给“中国第一首诗”确定一个可信的创作年代。劳动中的节奏、祭祀中的祝颂、集体舞乐和个人抒情，都可能参与了早期歌辞的形成。它们是理解诗歌起源的不同路径，而不是已经得到完整证明的单一起源公式。

一些被归于上古人物的歌谣，见于较晚形成或传抄的文献。它们可以反映后世对古代的理解，却不能仅凭题署就认定为史前时期原样保存的作品。“出现于最早的传说”和“拥有最早的可靠文本证据”，是两回事。

到了《诗经》，我们才拥有一部规模可观、传承系统相对清楚的早期诗歌总集。其内容大体反映西周至春秋时期的生活，四言句式占主导，重章复沓、赋比兴以及诗乐结合构成重要特点。不过，《风》《雅》《颂》并不分别等于纯粹的“民歌”“文人诗”“宗教诗”；创作、采集、表演与编订共同塑造了今天看到的文本。[^shijing]

战国楚地的歌辞及屈原传统，则将长篇抒情、神话想象、地方文化与个体政治经验结合起来。楚辞的句式和语气与《诗经》有显著差异，对后世辞赋、诗歌意象和抒情主体的塑造影响深远。这里的“楚辞”既可以指一种文体传统，也可以指汉代以后整理而成的总集，二者不能混同。

### 2.2 代表人物及其贡献

| 人物或创作群体 | 主要贡献 | 需要保留的限定 |
|---|---|---|
| 《诗经》的无名创作者、乐人及编订者 | 建立了后世反复借鉴的语言、节奏、意象和伦理表达方式 | 很多作品不能确定个人作者，不能将集体传承强行改写成个人创作史 |
| 孔子及儒家传诗传统 | 推动《诗》进入教育、解释和经典化过程 | “孔子删诗”是传统说法，不宜作为无争议的编纂史事实 |
| 屈原 | 将持续而强烈的自我陈述、政治理想与神话世界结合，扩大长篇抒情的表现能力 | 传为屈原所作的篇章，并非每篇的作者归属都毫无争议 |
| 宋玉及楚辞后继者 | 延展楚辞的语言与感伤传统，推动其与辞赋之间的联系 | 若干传世篇章的署名及形成过程仍须分别考证 |

### 2.3 存量分析

《诗经》通常计有正文**305篇**，另有**6篇只有篇名而无正文的笙诗**。若统计篇目，可以说305篇正文加6个有目无辞的篇目；若统计可阅读的诗歌正文，就不应写成311首完整诗。[^shijing]

这个数字的可信度较高，是因为对象是一个边界相对稳定的传世定本。但305篇不是“全部先秦诗歌”：逸诗、其他古籍中的歌谣以及出土文献中的相关材料，都在这一范围之外。

楚辞则不宜与《诗经》直接套用同一计数规则。《九歌》《九章》等包含内部篇章，篇、章、组诗与卷并非一一对应。传统王逸注本的卷次，也不能直接换算成同样数量的独立诗作。本报告因此不列一个未经逐篇核对的“先秦诗歌合计数”。

**阶段结论：** 可明确确认《诗经》的305篇正文规模；但先秦诗歌总体存量仍需将传世总集、散见歌谣与出土材料分层统计。早期诗歌具有奠基意义，并不意味着它拥有最多的传世篇数。

## 三、秦汉：乐府传统与五言诗的生长

### 3.1 主要介绍与特点

秦汉时期，一方面延续礼乐歌辞和楚辞传统，另一方面逐渐形成更适合叙事、对话及个人抒情的五言表达。乐府首先与音乐机构和活动有关，后来才成为诗歌分类中的重要名称；并不是所有被后人归入“汉乐府”的作品，都能直接还原为汉代民间采集的原始记录。

汉代乐府作品中，战争、劳役、婚姻、贫困和家庭关系获得了鲜明表达。许多作品依靠人物动作与对话推进，而不只是抽象抒情。至东汉后期，文人五言诗逐渐成熟，《古诗十九首》所代表的生命感、离别感和时间意识，成为后世抒情诗的重要资源。

这里还应避免“汉代文学就是汉赋”的误解。赋在当时确实具有突出地位，但若讨论诗歌发展，乐府与五言诗是另一条不可省略的线索。

### 3.2 代表人物及其贡献

| 人物或群体 | 对诗歌发展的作用 |
|---|---|
| 汉代乐府歌辞的无名创作者与传唱者 | 扩大叙事诗、对话体和日常生活题材的表现范围 |
| 刘邦等早期政治人物 | 留下将政治经验、身份表达与歌辞结合的个体创作实例 |
| 张衡、秦嘉等文人 | 参与文人五言、七言表达的探索，使个人情感与书面诗歌的联系更紧密 |
| 《古诗十九首》的无名作者群 | 以较为成熟的五言形式表达离别、失意与人生有限感，影响后世文人诗的基本语调 |
| 汉末建安诗人 | 将五言诗进一步推向个人化、时代化的表达；其主要发展在下一阶段合论 |

### 3.3 存量分析

汉典的相关介绍采用汉乐府诗现存**四十余首**的传统说法。使用这一数字时，应当将它理解为特定乐府作品群的概述，而不是所有汉代诗歌的总数。古代目录中的歌诗著录数与这一传世作品群，也不能直接相减以计算“失传比例”。[^hanyuefu]

《古诗十九首》的**19首**是后世总集所确立的选录单元，不是“东汉只剩19首文人诗”。其中作品的作者、确切年代及形成背景并不都能确定，也不宜无条件与前述乐府数相加。

研究整个时期，应使用覆盖文人诗、乐府、谣谚与残篇的综合性整理本。逯钦立《先秦汉魏晋南北朝诗》是重要基础，但它跨越多个历史阶段，全书135卷的规模不能转写成汉诗首数。[^lu]

《孔雀东南飞》等作品尤其能说明断代的复杂性：作品所叙事件的时代、文字形成的时代、最早见于现存文献的时代，可能不同，不能只凭故事背景归类。

**阶段结论：** 可以确认若干重要作品群的规模，尚不能据这些局部数字给出可信的秦汉全阶段存诗总数。秦代也不应因缺少便于统计的独立总集，就在统计表中被记为零。

## 四、汉末至魏晋：文人主体、生命意识与诗歌个性

### 4.1 主要介绍与特点

从汉末建安到魏晋，诗歌中的个人声音变得更加鲜明。战争经验、政治抱负、生命短促、人格选择和人与自然的关系，成为持续展开的主题。

建安诗人既继承乐府，也使文人五言诗获得更强的表达能力。正始时期，政治压力与思想变化促使部分诗歌趋于含蓄、象征和多义。两晋诗坛并非只有玄言诗：咏史、赠答、游仙及田园等方向都在发展。陶渊明的意义，正是在于将日常生活、人格实践与自然经验结合，使平淡语言能够承载深厚思想。

把这一时期概括为“文学自觉”有其解释力，但不能理解为先前的人没有审美意识。更准确地说，是作家身份、作品风格和文学价值获得了更集中、更明确的讨论。

### 4.2 代表人物及其贡献

| 人物 | 主要贡献 |
|---|---|
| 曹操 | 将乐府形式与政治抱负、时代忧患结合，形成苍劲简练的表达 |
| 曹丕 | 推动七言诗及细腻个人抒情的发展，其文学论述也强化了作家与文体意识 |
| 曹植 | 丰富五言诗的语言、结构和抒情强度，成为后世诗歌创作的重要参照 |
| 王粲 | 将流离与时代创伤转化为具体而有力度的诗歌经验 |
| 阮籍、嵇康 | 拓展含蓄寄托、人格书写以及诗歌与思想生活的联系 |
| 左思、郭璞 | 分别在咏史、游仙等领域，扩大现实批判与想象性表达的空间 |
| 陶渊明 | 使田园生活成为具有主体选择和伦理意味的诗歌世界，而不只是景物背景 |

### 4.3 存量分析

这一时期的传世作品比《诗经》复杂得多：有相对集中的个人作品，也有从史书、类书、总集和注释中辑出的零篇残句。现代整理本的规模因此在很大程度上取决于辑佚范围。

例如，阮籍五言《咏怀诗》通行编为**82首**，是边界较清楚的一个作品群；但这既不是阮籍全部诗歌的数量，也不是魏晋诗歌总量。[^ruan] 同一时期作品还可能因作者跨越汉魏、魏晋或晋宋而出现不同的断代归属。

本次核验确认了逯钦立总集的135卷体系，但未取得足以逐项核对的魏晋分期首数。网络上关于该书总收诗数的不同说法，不能在未说明是否包含谣谚、残句和重出作品时，直接移用为此阶段的数据。[^lu]

**阶段结论：** 这一时期可以开展以作者别集和作品群为单位的可靠计数，但全阶段合计仍需底本级复核。个人风格的突出，也不应被误读为无名歌辞退出了诗歌史。

## 五、南北朝与隋：山水、民歌、宫廷文学与声律探索

### 5.1 主要介绍与特点

南北朝诗歌的面貌并不单一。山水逐渐成为可以独立观照、细致描摹的对象；南方歌辞展现城市、江河交通与情爱生活，北方歌辞则保存了战争、迁徙和不同文化接触的经验。文人诗与民歌之间存在持续交流，不能将二者划成互不相通的系统。

齐梁时期，对汉语声调与诗歌节奏的讨论日益细密，永明声律探索为后来的近体诗提供重要条件。但唐代律诗并非在某一年突然由一个人“发明”，而是经过持续实践才逐渐定型。

宫体诗扩大了细部描写和语言技巧，也受到题材与宫廷环境的限制。将其一概视为没有文学价值，会遮蔽诗歌技法的发展。隋代时间较短，却是南北文学传统进一步汇合的重要过渡。

### 5.2 代表人物及其贡献

| 人物或群体 | 主要贡献 |
|---|---|
| 谢灵运 | 将山水观察、行旅过程与情思组织结合，拓展山水诗的表现方式 |
| 鲍照 | 在乐府、七言歌行和社会不平的表达上具有开拓作用 |
| 谢朓 | 以清新、凝练的景物描写与声律经营，影响唐代山水诗及近体诗 |
| 沈约及永明诗人 | 推进声调与格律问题的自觉讨论，为后来的律诗成熟提供条件 |
| 庾信 | 贯通南北文学经验，将身世之感、历史创伤与精密表达结合 |
| 南北歌辞的无名作者、歌者及整理者 | 保存文人别集之外的语言、生活与表演传统 |

### 5.3 存量分析

游国恩等《中国文学史》相关章节列举了《乐府诗集》所保存的若干歌辞类别：吴声歌**326首**、西曲歌**142首**、神弦曲**18首**。三项相加为**486首**，但这只是所列三类作品的合计，不是全部南朝诗歌，甚至不能未经进一步清点就等同于全部南朝民歌。[^nbsongs]

同一章节所说的北方“六十多首”，具体指**现存鼓角横吹曲**，不应扩写成整个北朝只保存了六十多首诗。作品类别之间的传唱、改写及文人参与，也需要在更细的研究中区别处理。

这些数量足以说明南北歌辞保存状况很不均衡，却不能证明南方历史上的创作量就是北方的若干倍。保存渠道与后世编纂选择，都可能造成差距。

文人诗及隋诗仍应另行计数。本报告未核得南北朝与隋全部诗作的统一首数，不用民歌分项补填这个空缺。

**阶段结论：** 可以确认若干歌辞类别达到数十至数百首规模；但“南朝民歌多、北朝民歌少”的传世现象，不等于整个南北文学生产能力的比较。

## 六、唐与五代：诗体成熟、创作扩展及词的发展

### 6.1 主要介绍与特点

唐代诗歌的重要性，一方面在于古体、律诗、绝句、歌行等多种形式达到高度成熟，另一方面在于这些形式被用于丰富而广泛的生活经验。科举、士人交往、地方任职、行旅、寺院与城市文化等，共同构成诗歌传播的环境，不能把唐诗繁荣归结为单一制度。

“初唐、盛唐、中唐、晚唐”适合描述诗风变化，却不是互不重叠的四个封闭阶段：

- **初唐：** 整理前代语言与声律经验，近体诗逐渐定型。
- **盛唐：** 山水、边塞、都市与个体生命经验获得高度凝练的表达。
- **中唐：** 社会批评、日常生活、奇崛语言与新的抒情方式并行发展。
- **晚唐至五代：** 诗歌继续在精密结构与个人感受中深化，文人词也逐渐形成重要传统。

词依托音乐曲调发展，并不是“到了宋代才突然出现”。敦煌曲子词、晚唐五代文人词和不同地域的歌唱实践，都是理解词体形成的必要材料。

### 6.2 代表人物及其贡献

| 人物 | 主要贡献 |
|---|---|
| 初唐四杰、陈子昂 | 扩大诗歌题材和表达气象，在不同方向上反思宫廷诗风 |
| 沈佺期、宋之问 | 推进近体诗格律的稳定化 |
| 王维、孟浩然 | 丰富山水、田园、行旅与静观经验的诗歌表达 |
| 李白 | 将乐府、歌行、想象力与强烈主体意识结合，展现古体诗的自由与张力 |
| 杜甫 | 将个人处境、社会观察和历史经验融入多种诗体，尤其扩展律诗的表现容量 |
| 高适、岑参 | 使边地经历、战争经验和异域感受获得不同于内地生活的语言形式 |
| 韩愈、孟郊、白居易、元稹 | 分别推动语言实验、苦吟传统及关注社会现实的诗歌实践 |
| 杜牧、李商隐 | 深化咏史、个人情感、象征和结构经营 |
| 温庭筠、韦庄、李煜 | 推动文人词的语言与抒情方式发展，为宋词提供重要资源 |

### 6.3 存量分析

唐五代诗歌至少应区分两个整理层次：

| 整理成果 | 可核查的规模 | 本报告采用的解释 |
|---|---|---|
| 清编《全唐诗》 | 900卷，诗48900余首，作者2200余人 | 传统基础总集的收录规模，并非截至今天的全部已知唐诗 |
| 陈尚君纂校《唐五代诗全编》，2024年出版 | 50册、1225卷，诗57000余首，诗人3700余名 | 新近综合整理成果的收录规模，不与旧本及其补编相加 |

前一组数据见中国出版集团的书目介绍；该页面还介绍了增订内容，因此必须将“清编原有规模”和后来附入的补辑区分开。后一组数据见中国全民阅读网的图书介绍，复旦大学发布的首发消息也确认了2024年五十册本的正式出版。[^tangold][^tangnew][^tanglaunch]

以两组约数的中心值作尺度比较，57000比48900高约**17%**。这反映的是整理成果规模的变化，不能解释为“恰好新发现了8100首独立唐诗”：新整理同时包含辑佚、去重、辨伪、作者改署和断代调整。

唐五代词应另列。《花间集》收晚唐至五代**18位词人、500首词、10卷**，是一个明确的选集规模，但远不是全部唐五代词。敦煌曲子词、南唐词及其他散见作品，需要另外纳入。[^huajian]

**阶段结论：** 讨论唐五代诗歌的现有整理规模，可以采用“约5.7万首”这一量级，同时注明2024年总集口径；若仍使用“约4.9万首”，必须说明那是传统《全唐诗》的规模。

## 七、宋、辽、金：诗词并盛与并立政权中的文学

### 7.1 主要介绍与特点

宋代不能只用“宋词”概括。宋诗持续开拓日常经验、学问、议论和观察方式，在语言组织与思考路径上形成多种特点。“以文为诗”“以议论为诗”是解释部分宋诗实践的概念，并不意味着宋诗没有情感与形象。

宋词依托城市文化、音乐表演和文人交往，题材与结构进一步丰富。婉约、豪放可以作为入门性的风格提示，但不能把词人及其全部作品固定在两类中。李清照、苏轼、辛弃疾等人的实际创作，都比这种二分复杂。

辽、金与两宋存在长期并立关系。尤其金代，汉语文学不仅有对唐宋传统的接受，也有北方社会与多族群交流形成的经验。将辽金文学仅仅当作宋代文学的附属，会损失重要的历史维度。

### 7.2 代表人物及其贡献

| 人物 | 主要贡献 |
|---|---|
| 欧阳修、梅尧臣、苏舜钦 | 在北宋诗文革新中改变诗歌题材、语言与审美取向 |
| 苏轼 | 打通诗、词、文与生活经验之间的联系，显著扩大词的表现范围 |
| 黄庭坚 | 以典故组织、语言锤炼和结构变化建立高度自觉的诗法，对江西诗派影响深远 |
| 柳永、周邦彦 | 在慢词、铺叙、音律和章法方面发展词体的表现能力 |
| 李清照 | 将精细的语言感受、个人生活经验与时代变故融入词中，并参与词体理论讨论 |
| 陆游、杨万里、范成大 | 分别在国家情怀、即时观察、田园与地方生活等方面扩展南宋诗境 |
| 辛弃疾、姜夔 | 分别拓展词的历史与政治表达，以及清空、精密的音律和意象结构 |
| 耶律倍等辽代作者 | 提供辽代汉语文学及跨文化交往的观察线索 |
| 元好问 | 集金代诗歌之大成，并通过《中州集》等保存前代及当代作家的文学记忆 |

### 7.3 存量分析

**宋诗。** 北京大学组织编纂的《全宋诗》共72册，1998年出齐。关于首数，莫砺锋在2016年《光明日报》刊载的演讲中使用“接近25万首”的表述；本报告采用这一有明确署名出处的文献约数，而不把网络常见的“27万首”当作已核实精确值。[^songproject][^songcount]

作者人数也存在不同概述方式：1999年同日刊载的两篇评论，一篇说8900余家，另一篇说9000多家。报告保留这一差异，不将其擅自解释为已查明的版本增删关系。[^song8900][^song9000]

**宋词。** 中国出版集团所载中华书局《全宋词》介绍，列出词人**1330余家**、词作**19900余首**，另列**残篇530余首**。因此，更合适的写法是“约2万首词，另有按来源单列的残篇”，而不是把残篇折为同等完整作品后给出精确总数。[^songci]

**金诗。** 2021年中华书局《新编全金诗》书目简介说明收作者**600余人**、诗作**12000余首**。本报告采用这一版本的约数，不将旧版作者数与新版作品数拼接。[^jin]

**辽诗及其他材料。** 本次未核得能够与上述总集口径直接对应的辽诗统一首数。辽、金的汉语诗歌与其他语言文献也不能在未说明语种范围时合并。

若仅比较整理成果的诗歌量级，接近25万首的宋诗约为5.7万首唐五代诗的**4.4倍**。这一比较可以纠正“宋代主要写词、诗很少”的印象，但不能证明宋人的实际创作量、平均创作能力或文学成就就是唐人的4.4倍。

**阶段结论：** 宋诗与宋词必须并列观察；辽、金应保持各自的历史位置。这里呈现的是不同传统的共同发展，而不是“诗退出、词接替”的单线过程。

## 八、元代：诗词延续与散曲的突出发展

### 8.1 主要介绍与特点

元代文学不能只剩下“元曲”两个字。诗、词、散曲和戏剧并行存在，不同文体拥有不同的创作者、传播途径和受众。

散曲借助曲牌、衬字和较为灵活的语言组织，把口语、戏谑、世情与个人感慨带入新的表达形式。诗歌则继续承担士人交往、地方生活、历史记忆与身份表达等功能。多族群作者的汉语创作，也是元代诗歌的重要特点。

从数量上理解元诗，还需要留意：一些“全元”整理成果的文学断代并不简单等于1271年至1368年的王朝年限，可能涉及蒙古国时期或跨金元、宋元的作者。

### 8.2 代表人物及其贡献

| 人物 | 主要贡献 |
|---|---|
| 赵孟頫、虞集、杨载、范梈、揭傒斯 | 从不同方向延续并调整唐宋以来的诗学传统，参与元代文人诗风的建构 |
| 萨都剌 | 在汉语诗歌中表达城市、行旅、地域与多文化经验 |
| 王冕 | 将个人处境、社会观察与题画诗等形式结合 |
| 关汉卿、马致远、白朴、张可久 | 推动散曲的语言、题材和抒情方式发展；其中部分作者同时在戏剧史上占有重要位置 |
| 张养浩 | 将历史感慨、政治关怀和民生经验写入散曲 |

### 8.3 存量分析

杨镰主编、中华书局出版的《全元诗》为68册，图书馆书目介绍列出**近5000位诗人、约14万首诗**。这是相当庞大的传世整理规模，足以说明元诗不能在文学史叙述中被忽略。[^yuan]

散曲必须另计。隋树森《全元散曲》的书目介绍列出**213位作者、小令3853首、套数457套**。2018年修订版的介绍又单独说明了新增作者与曲目，因此这里将前述数字作为书目所述的基础规模，不冒充修订后重新去重核定的总数。[^yuanqu]

不能写成“元代共有4310首散曲”，因为这把小令和套数处理成了相同单位；更不能将戏剧的折、套、曲牌也直接加入“古诗词首数”。元词另有专门总集与补辑，本报告没有将其与诗、曲混合计算。

**阶段结论：** 元诗属于约十余万首的整理规模；散曲则应分小令与套数统计。元代文学的文体重心变化，不意味着诗词停止发展。

## 九、明代：复古、性灵与广泛的诗词生产

### 9.1 主要介绍与特点

明代诗坛围绕如何理解和继承前代形成持续争论：应当学习哪一时期的典范，怎样避免模拟，个人经验与既有规范如何协调。这些问题贯穿复古、性灵等不同主张。

前后七子的复古运动，并不是所有作品都只剩模仿；公安派、竟陵派等也不只是简单反传统。不同流派既有理论对立，也共享大量阅读资源和交往网络。与此同时，商业出版、地方文教、文人结社及女性写作，使诗词创作与传播的社会范围更加广泛。

明词在经典选本中的能见度相对较低，不等于它不存在。论述明代时，应同时观察诗、词、散曲及其传播环境，而不能只以“唐宋之后的衰落期”一语带过。

### 9.2 代表人物及其贡献

| 人物 | 主要贡献 |
|---|---|
| 高启 | 以广泛取法与个人才情形成明初重要诗歌成果，连接元明之际的文学变化 |
| 李东阳 | 在台阁文学及诗歌声调、格法的讨论中占有重要位置 |
| 李梦阳、何景明 | 以复古主张改变诗坛的规范意识与学习对象 |
| 李攀龙、王世贞 | 推进复古诗学及其传播，同时参与大规模文学评议与文献活动 |
| 袁宏道及公安派 | 强调个人性情和当下感受，反对缺乏真实经验的摹拟 |
| 钟惺、谭元春 | 通过创作与选诗形成另一种审美趣味，影响明末诗坛 |
| 陈子龙、夏完淳 | 将易代经验、个人命运与诗词表达相结合；归代需要具体处理 |
| 薛素素等女性作者 | 提供男性士人别集之外的创作经验，提示文献保存与经典选择的性别差异 |

### 9.3 存量分析

明代是本报告不能负责任地给出统一存诗总数的阶段之一。网络常见“明诗约50万首”等说法，但本次未取得足以确认其统计对象、去重方法和完成状态的直接依据，因此不把这一数字列入已核实结果。

能够确认的是，1997年《跨世纪的古籍整理工程——〈全明诗〉》的摘要预计，工程完成后将有**200册以上、超过1亿字**。这是当时对工程体量的规划，既不是已经出版的册数，也不是独立诗作首数。[^mingproject]

另一项可以确认的成果是饶宗颐初纂、张璋总纂的《全明词》，2004年中华书局六册本具有明确书目信息。但本次核对的书目页面没有列出可核实的词作总首数，因此不借用其他来源不明的数字补填。[^mingci]

明诗、明词资料分布在别集、选集、地方志、家集及其他文献中。一个总集选入多少作者，不能直接推算他们所有存世作品的数量；依据现存别集种数乘以“平均每集若干首”，也会受到诗文混编、重复刊刻和长尾作者差异的严重影响。

**阶段结论：** 明代文献规模庞大已有充分的工程性依据，但本报告对明诗、明词的全阶段首数均保留“未核定”。这是资料核查的边界，不是对明代诗词成就的否定。

## 十、清代至晚清：大规模积累、词学复兴与古典形式的转变

### 10.1 主要介绍与特点

清代诗歌同时存在多种学习路径和评价标准。神韵、格调、性灵、肌理等主张，反映的是诗人如何理解语言、知识、情感与传统之间的关系，不宜被写成彼此整齐接替的流派年表。

词在清代得到持续整理与重新评价。浙西词派、常州词派等推动了创作与词学讨论，词既可以关乎个人情感，也可以具有寄托、历史和伦理意味。清词不是宋词之后一个可以省略的附录。

晚清面对战争、制度变化、海外知识和新的传播媒介，古典诗歌继续吸收新经验。其变化不是“旧体诗突然死亡”，而是旧有文体面对新世界时出现重组，同时逐渐与后来兴起的新诗构成新的文学关系。

### 10.2 代表人物及其贡献

| 人物 | 主要贡献 |
|---|---|
| 顾炎武、黄宗羲、钱谦益、吴伟业 | 从不同立场和形式处理易代经验、历史记忆与个人处境；部分作者跨明清 |
| 王士禛 | 推广神韵诗学，重视含蓄、余味及特定的审美境界 |
| 沈德潜、袁枚、翁方纲 | 分别从格调、性灵和学问等方向参与诗学争论，形成不同的创作与评选标准 |
| 朱彝尊、陈维崧、纳兰性德 | 在词的风格、题材和词史评价上作出不同贡献 |
| 张惠言、周济 | 推进词学中的寄托解释和理论建构，影响常州词派及后世研究 |
| 龚自珍、魏源 | 将政治忧患、思想变化和强烈个人感受写入古典诗歌 |
| 黄遵宪 | 以海外观察与新知识扩展旧体诗所能表现的现代经验 |
| 秋瑾及晚清其他女性作者 | 使性别处境、公共行动与国家危机进入新的诗歌表达 |
| 郑文焯、朱祖谋、况周颐、王鹏运 | 体现晚清词学与词体实践的深化；跨入民国的作品应另行断代 |

### 10.3 存量分析

清诗数量最容易在传播中被写成惊人的确定值。罗时进2021年《再论〈全清诗〉编纂的重要性与可行性》提出：清诗作者可能约10万，清诗遗存据测算可达**800万至1000万首**。[^qingestimate]

这一说法具有明确的署名学者来源，值得重视，但使用时至少需要说明：

1. 它是对清诗遗存规模的**估算**，不是已出版《全清诗》的逐首计数。
2. 800万至1000万不是本报告计算的统计置信区间。
3. 文章涉及总集、别集目录等文献线索，但本次核验的公开文章不足以让读者复算出完整估计过程。
4. 估算中的作品单位、残篇处理、去重规则以及清末民初界限，还需要专门方法说明。
5. 2021年文章对编纂状态的判断，只能按其发表时间引用，不能据此断言2026年没有任何后续进展。

因此，本报告写作“**罗时进估计清诗遗存为800万至1000万首，尚非核定总量**”，不写“现存清诗准确为1000万首”，也不据此计算清诗占全部古诗的精确百分比。

清词另有连续的整理工程。南京大学文学院2013年的项目介绍明确说明，《全清词·顺康卷》于**2002年5月出版，20册、850万字**；《全清词》拟按顺康、雍乾、嘉道、咸同、光宣分卷。[^qingci] 这说明必须区分全集规划与分卷成果，不能把顺康一卷当成全部清词，也不能把册数、字数折成首数。

**阶段结论：** 清代很可能是古典诗词文献整理中体量最大的部分之一，但现有可引用的宏观估算与逐篇核定之间仍有很长距离。越是庞大的数字，越需要明确的统计方法，而不只是更醒目的标题。

### 11.2 数量比较的三条主要认识

**第一，经典地位与保存数量没有线性关系。** 《诗经》的规模远小于后世断代总集，却构成了后世不断重释的基础。明清作品数量巨大，也不等于它们已经得到同等充分的研究与阅读。

**第二，越晚的时期通常拥有更多可利用文献，但不能只用“写得更多”解释。** 印刷、文集编刊、地方文献积累与保存距离较近，都可能增加今天能看到的数量。早期作品经历了更长时间的散佚与筛选。

**第三，整理史本身会改变我们看到的文学史。** 旧总集到新总集的数量变化，不只是发现新诗，还可能是纠正重出和误署。可靠的统计允许数字增加，也允许数字减少。

### 11.3 为什么本报告不给“古诗词总计”

目前不宜将上表直接加总，原因不是计算困难，而是相加对象不满足同一条件：

- 部分行是全体性整理，部分行只是选集或局部作品群。
- 明代及若干早期阶段缺少本次可核定的统一首数。
- 清代使用估算，其他时期多使用整理本数，证据性质不同。
- 跨朝作者和作品可能在不同总集中重叠。
- 诗、词、小令、套数、残篇并非相同统计单位。
- 各整理成果的收录年代、考订成果与版本处理并不一致。

因此，“中国古诗词到底有多少首”在目前更适合得到一个**分文体、分时期、分整理层级的答案**，而不是一个看似完整、实际无法复核的总和。出于同样原因，本报告不绘制混合这些数字的总量饼图或朝代排名柱状图。

## 十二、系统整理中国古诗词的意义

### 12.1 从名篇阅读走向文学整体

选本擅长帮助人们进入文学，却也容易让少数名家代表整个时代。系统整理可以恢复地方作者、普通士人、女性、僧道及不同群体的写作，让诗歌史从“几位伟大诗人的接力”变成更完整的文学生活史。

这不意味着取消审美评价，而是先让评价拥有充分的材料。缺少整理，许多作者甚至没有进入被评价的范围。

### 12.2 保存语言、声音与表达方式的历史

诗词保存了词汇、语法、语音关联、典故以及情感表达的变化。诗、词、曲与音乐的联系，也提示我们：书面文字只是历史作品的一部分，曲调、表演及使用场景同样重要。

对这些材料进行可靠整理，可以帮助研究汉语的发展，以及不同文体如何组织节奏、记忆和意义。但不能把现代普通话中的读音直接当作所有时代的韵律依据。

### 12.3 为社会文化史提供细密材料

诗词涉及旅行、饮食、疾病、家庭、物产、战争、职业和地方交往，能够补充正史与制度文献较少照顾的经验层面。

不过，诗歌不是未经加工的生活记录。夸张、用典、拟古和虚构都可能影响解释。研究物候、气候或经济生活时，不能把每一句景物描写都当作可直接测量的历史事实。

### 12.4 让公共教育与数字研究建立在可信文本上

可靠文本有助于教学、阅读推广、翻译和跨文化交流，也能为作者关系、地理分布、典故传播和文体变化研究提供基础。

对于人工智能应用，价值不在于简单堆积更多文本，而在于建立具有来源、版本和校订记录的资料。一个能够解释出处、承认存疑的系统，比一个总能流畅补全“古诗”的系统更有学术价值。

## 十三、整理中的主要挑战与可行路径

### 13.1 主要挑战

| 挑战 | 典型问题 | 应对原则 |
|---|---|---|
| 散佚与分散保存 | 作品见于别集、类书、地方志、碑刻、家谱或域外汉籍 | 建立来源目录，记录检索范围与未覆盖部分 |
| 作者身份与断代 | 同名异人、字号变化、代作、伪托、跨朝创作 | 分开记录作者实体、题署和归属判断，不凭单一姓名合并 |
| 作品与版本的关系 | 一诗多题、异文重出、互见、改稿、组诗拆分 | 区分作品身份与文本见证；保留异本，不把去重做成删证据 |
| 文体与计数单位 | 诗词互见、曲套拆分、残句、仅存篇目 | 提前公布分类和计数规则，允许无法确定的条目单列 |
| 古籍文字识别 | 异体字、版刻漫漶、手写体、夹注混入正文 | 识别结果与底图关联；重要文本人工复核 |
| 规范化与原貌冲突 | 简繁转换、异体字统一、现代标点改变句义 | 原文层与检索规范层分离，不静默覆盖底本文字 |
| 保存偏差与经典偏差 | 名家材料多、弱势群体材料少；知名总集反复被复制 | 明示语料覆盖面，不把可检索数据当作历史人口的随机样本 |
| 授权与使用边界 | 古代原作、现代校勘、注释、影像和数据库条款并不相同 | 分层核查授权；不能因原作年代早，就默认现代整理成果可任意复制 |
| 长期维护 | 链接失效、项目中断、编号变化、修订不可追溯 | 保持稳定标识、版本发布和更正记录，支持长期保存 |

### 13.2 优先建立“可追溯”，再追求“更完整”

一个可持续的整理过程可以分为四步：

1. **先做文献目录。** 确认哪些版本、别集和总集已经进入范围，哪些材料尚未获取，哪些只有目录记录。
2. **再做文本层整理。** 保留底本位置、卷页、作者题署和原始文字，将校订与正文区分。
3. **逐步建立作品关系。** 标注互见、疑似重出、改题、异本和组诗结构，交由文献判断决定是否合并作品身份。
4. **最后发布可复核统计。** 与数字一同公布规则、覆盖范围、版本日期、待考条目和修订记录。

不必等待所有问题解决后才发布阶段成果，但不能把阶段成果标成已经穷尽的全集。

### 13.3 一份合格的数量报告至少应公布什么

| 必要字段或指标 | 用途 |
|---|---|
| 所据底本、整理本及版本日期 | 让读者知道统计的是哪一个文本集合 |
| 时间与地域、语种、文体范围 | 防止标题很宽，实际对象很窄 |
| 作品标识与文本见证标识 | 区分“同一首诗”与“同一首诗的不同记载” |
| 完整作品数、残篇数、仅存篇目数 | 避免把证据完整程度不同的材料混计 |
| 组诗拆分规则 | 解释题目数与作品数的差异 |
| 重出、疑伪、存疑作者的处理规则 | 使去重与考订过程可审查 |
| 已覆盖和未覆盖的文献范围 | 防止把尚未整理误判为不存在 |
| 与上一版的增删及理由 | 区分新发现、校订和规则变更导致的数字变化 |

对于无法可靠估算的部分，公布“未核定”比给一个没有依据的近似数更有价值。对于有学者估算的部分，则应同时公布作者、时间、估算对象及可复算程度，避免估算在多次转述后变成事实。

## 十四、结语

中国古诗词的发展，不是一条从《诗经》走向唐诗、再由宋词接替、最后归于衰落的直线。不同文体长期并存，不同群体不断进入创作，旧形式也持续吸收新的经验。

数量研究有助于修正阅读习惯造成的印象：宋诗并不少，元代不只有曲，明清也不是可以忽略的尾声。但数字只有与版本、文体和保存条件联系起来，才能成为知识；脱离这些条件，它很容易退化成排行榜。

系统整理古诗词最重要的成果，不应只是一个更大的作品总数，而应是一套能够回答以下问题的可靠材料：**这首作品从哪里来，以什么文本保存，为什么归给这位作者、这个时代，还有哪些判断尚未确定。** 当这些问题能够被持续回答，诗歌遗产才真正从分散的古籍材料，转化为可阅读、可讨论、可检验、可继续积累的公共知识。
