# 诗歌总集

《诗歌总集》收集和整理中文诗词曲赋，也收录部分散文，目前**收录 370卷，共计约37万首诗词歌赋**。创建这个仓库，是希望逐步整理出一份系统、完整、质量可靠的诗词数据集，并尝试借助大语言模型做校正、鉴赏和评分。

目前已有分卷数据、按作者拆分的数据，以及一批 AI 鉴赏结果。收录范围、文本质量和出处信息仍需继续核对。

### 已知数据问题

<!-- quality:start -->

- **出处缺失**：342,226 条记录的 `collection_info` 为空。
- **元数据不全**：460 条未注明朝代，14 条标题为空。
- **去重范围**：主数据有 369,597 个不同的 `uuid`，重复标识条目数为 0；这项检查不能排除内容重复或异文。
- **目录差异**：主数据中有 5 个标识未出现在作者目录中，另有 1 条同标识记录的字段不同。
- **鉴赏关联**：鉴赏文件有 19,058 个不同的 `uuid`，与主数据相同的有 0 个。暂不能直接按 `uuid` 关联，也不能据此计算鉴赏覆盖率。

<!-- quality:end -->

此外，文本仍有繁简混用、异体字和缺字等情况。校对时需要区分版本差异与录入错误。部分记录虽然保存了书名、卷名，但具体版本和获取来源还需要补充。

### AI 鉴赏与评分

[鉴赏文件](appreciation/AI鉴赏与评分/)按 80–85、85–90、90–95、95–100 四个分段保存。摘要和分数分别位于 `appreciation.summary` 与 `appreciation.score`。

评分原本是为了帮助读者从大量作品中筛选阅读对象。文学评价有主观性，现有分数仅作为实验结果保留。后续需要补充生成方法，并核对鉴赏中的文本解释和背景判断。

## 数据格式与使用

- [`volumes/`](volumes/)：按卷保存的主数据，批量处理以此为准。
- [`by_poets/`](by_poets/)：按作者拆分的文件，便于查阅。
- [`appreciation/`](appreciation/)：AI 鉴赏和评分，含额外字段。
- [`processors/`](processors/)：统计与处理脚本。

以下记录摘自[第 54 卷](volumes/volume_054.json)，保留文件原文：

```json
{
  "uuid": "8b54cc80f5d44d75239539ba62fbbf83",
  "title": "辋川集 鹿柴",
  "author": "王维",
  "content": "空山不见人，但闻人语响。\n返景入深林，復照青苔上。",
  "dynasty": "唐",
  "collection_info": null
}
```

`title`、`author`、`content` 为字符串；`dynasty` 可为 `null`。`collection_info` 是出处信息对象或 `null`，已有字段包括 `collection`、`volume`、`section` 等。`uuid` 请按现有值读取；当前仓库未附完整的标识生成实现。

使用 Python 3 标准库即可读取。在仓库根目录运行：

```python
import json
from pathlib import Path

path = Path("by_poets/唐-王维.json")
poems = json.loads(path.read_text(encoding="utf-8"))

for poem in poems[:3]:
    print(poem["title"], poem["author"])
    print(poem["content"])
```

本页统计由 [`processors/readme_stats.py`](processors/readme_stats.py) 生成。数据更新后可重新计算，结果同时写入本页和 [`docs/data-snapshot.json`](docs/data-snapshot.json)：

```bash
python3 processors/readme_stats.py
```
